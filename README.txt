APPLE MAPS NAVIGATION — PWA PACKAGE

Что это:
- index.html — текущий проект навигатора;
- manifest.webmanifest и иконки — установка как приложение;
- sw.js — кеш оболочки приложения (карта/поиск/маршруты не становятся полностью офлайн).

Как запустить:
1. Размести содержимое этой папки на HTTPS-хостинге (например, GitHub Pages).
2. Открой опубликованный HTTPS-адрес в Chrome на Android.
3. Меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».
4. Разреши доступ к местоположению, когда браузер спросит.

Важно:
- Нельзя просто открыть index.html из папки и ожидать полноценную PWA: для установки нужен HTTPS или localhost.
- Для навигации нужен интернет и работающий ключ/доступ к текущему сервису Mapbox.
- Сборка APK — отдельный следующий этап. Этот пакет делает установку PWA проще, но сам по себе не является APK.
- Service worker кеширует оболочку, но не кеширует внешние карты и не обещает офлайн-навигацию.
